# **MS/MS DDA-based proteomics data analysis**

This repository contains a workflow for analyzing shotgun proteomics (MS/MS, Data-Dependent Acquisition - DDA) data. Raw mass spectrometry files were processed using MaxQuant, and downstream statistical analysis was performed in R using DEP and limma.

## Dataset

**Source:** Pride dataset (PXD058080)

**Download:** http://cf.10xgenomics.com/samples/cell-exp/3.0.0/pbmc_10k_v3/pbmc_10k_v3_filtered_feature_bc_matrix.tar.gz](https://ftp.pride.ebi.ac.uk/pride/data/archive/2025/08/PXD058080/

**Input Files:** 
  * proteinGroups.txt (generated by MaxQuant)
  * experiment_annotation.txt:
      * Sample names
      * Conditions (Control, HS276, LLOMe, etc.)
      * Replicates

**Species:** Human


## Workflow

**1. MaxQuant Processing**
* Input: RAW MS files
* Output: proteinGroups.txt
* Filtering:
  * Remove reverse hits
  * Remove contaminants
  * Remove proteins identified only by site

**2. DEP Analysis (dep.R)**
* Data import and preprocessing
* Normalization
* Missing value imputation
* Differential enrichment analysis
**Outputs:**
* PCA plot
* Correlation matrix
* Heatmaps
* Volcano plots
* Protein overlap visualization

**3. limma Analysis (limma.R)**
* Linear modeling for differential expression
* Multiple condition comparisons
**Outputs:**
* CSV result tables (log2FC, p-value, adjusted p-value)
* Volcano plots
* Heatmaps
* PCA plot
